📚 3. Most Asked Questions – Easy to Medium
I’ve grouped the questions topic-wise and included short answer tips. Let’s go:

🔷 Recursion, Arrays, Strings
Question Tip to Prepare
Reverse a string / array Use two pointers
Fibonacci with & without DP Classic recursion vs memoization
Factorial (recursive) Base + recursive call
Palindrome string check Two pointer method
Longest Common Prefix Sort + compare or char by char
Anagram check Use sorting or hash map
Remove duplicates from array/string Set or hash map
Find the missing number in array of 1 to N XOR or Sum formula
Kadane’s algorithm Max subarray sum – high frequency
Merge two sorted arrays Classic merge process

🔷 Linked List, Stack, Queue
Question Tip to Prepare
Reverse a linked list (iterative + recursive) Very common
Detect loop in linked list Floyd’s cycle algorithm
Find middle of linked list Fast and slow pointer
Implement stack/queue using array or LL Class-based implementation
Balanced parentheses Stack-based approach
LRU Cache (logic-level) HashMap + Doubly Linked List (can just explain idea)

🔷 Trees & Bit Manipulation
Question Tip to Prepare
Inorder, Preorder, Postorder traversal Write iterative + recursive if possible
Height/Depth of tree Recursive logic
Count leaf nodes If node.left==null && node.right==null
Lowest Common Ancestor Recursive + path-based approach
Convert sorted array to BST Use mid as root recursively
Bit manipulation: Count set bits n & (n-1) method
Power of 2 check n & (n-1) == 0

🔷 Sorting & Searching
Question Tip
Binary Search Mid calc: l + (r - l)/2
Merge Sort / Quick Sort Recursion and partition logic
Search in rotated sorted array Modified BS
First and last occurrence of element BS with variation

🔷 Sliding Window / Two Pointer
Question Tip
Max sum subarray of size k Fixed window
Longest substring without repeating chars Sliding window + HashSet
Min window substring Tricky but common medium
Two sum / 3 sum Use map / two pointer based on sorted input

🔷 DBMS Questions
Question Short Answer
Normalization Reduce redundancy
1NF, 2NF, 3NF difference Keys + Partial + Transitive dependencies
ACID properties Atomicity, Consistency, Isolation, Durability
Indexing Speeds up read (based on keys)
Primary vs Unique Key PK = not null + unique, UK = just unique
Joins (Inner, Left, Right, Full) Know basic syntax and Venn diagram meaning
Transactions Group of SQL queries that are atomic

🔷 HTML, CSS, JavaScript
Question Short Answer
Difference between id and class id is unique, class is reusable
Box model Margin, Border, Padding, Content
Flexbox basics display: flex, justify and align content
DOM Manipulation document.querySelector, innerText, etc.
Event bubbling vs capturing Order of event propagation
var vs let vs const var = function scoped, let/const = block scoped
== vs === == checks value, === checks value + type
